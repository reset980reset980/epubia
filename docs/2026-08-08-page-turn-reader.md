# 2026-08-08 · EPUBIA 1.5.1 책 넘김 리더

## 목표

전자책 공개 샘플을 긴 웹 문서가 아니라 실제 책처럼 읽도록 만들고, 기존 연속 스크롤 방식과 접근성을 유지한다.

## 구현

- 공개 OCR/PDF 샘플에 기본 책 넘김 모드 추가
- 페이지를 드래그하면 손가락·포인터 이동량을 따라 3D 페이지가 회전하고, 거리와 속도에 따라 넘김 또는 복귀
- 이전·다음 버튼, 좌우 방향키, Page Up/Down, Home/End, Space 지원
- 현재 쪽·전체 장수·상단 및 하단 진행 표시와 URL `#leaf=N` 상태 동기화
- 목차에서 원하는 쪽으로 바로 이동
- 언제든 연속 스크롤 읽기로 전환 가능
- 모바일 단일 페이지 판형, 터치 스와이프, safe-area 대응
- `prefers-reduced-motion`에서는 장식 애니메이션 제거 및 즉시 상태 전환
- 서재 표지 카드에 포인터 기반 미세 입체 기울기·광택·페이지 가장자리 추가
- 메인 에디션 패널에 절제된 깊이 반응 추가

## 보존한 동작

- JavaScript를 사용할 수 없으면 기존 연속 문서가 그대로 표시됨
- 무료 HTML ZIP 책의 격리 iframe과 원본 상호작용은 변경하지 않음
- 유료 샘플의 서버 측 페이지 제한과 이미지 접근 제어는 변경하지 않음
- 관리자 출판·결제·구매 연계 경로는 변경하지 않음
