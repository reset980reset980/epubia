# 2026-08-08 · EPUBIA 1.6.0 곡면 종이책 리더

## 목표

공개 OCR/PDF 샘플을 실제 두 페이지 종이책처럼 펼쳐 읽고, 포인터·손가락 드래그 중에도 평면 회전이 아닌 연속적인 종이 곡면을 보여준다. 기존 연속 스크롤·접근성·샘플 제한은 유지한다.

## 구현

- 데스크톱과 모바일 모두 중앙 제본이 있는 두 페이지 펼침 구조
- 페이지를 22개(데스크톱) 또는 16개(모바일) 세로 스트립으로 구성하고, 각 스트립의 3D 접선 각도를 연결해 하나의 연속 곡면을 생성
- 현재 종이의 앞면·뒷면과 다음 펼침을 별도 레이어로 유지
- 드래그 진행도에 따라 곡률, 접힘 경계, 종이 명암, 중앙 투영 그림자를 매 프레임 갱신
- 정방향·역방향 드래그, 거리·속도 기반 완료/복귀, 스프링 자동 넘김
- 이전·다음 버튼, 좌우 방향키, Page Up/Down, Home/End, Space 지원
- 현재 쪽·전체 장수·상단 및 하단 진행 표시와 URL `#leaf=N` 동기화
- 목차 바로 이동과 연속 스크롤 읽기 전환
- 모바일 표지는 작은 반쪽 페이지에서도 잘리지 않도록 실제 표지 이미지를 중심으로 표시
- `prefers-reduced-motion`에서는 곡면 애니메이션을 만들지 않고 즉시 페이지 상태를 전환

## 참고 구현과 권리 경계

상호작용 기준은 `MengTo/sketchbook` 공개 데모의 두 페이지 펼침·중첩 스트립 곡면이다. 저장소에 명시적 LICENSE가 없으므로 원본 코드·이미지·폰트를 복사하지 않고 EPUBIA DOM 콘텐츠용으로 별도 구현했다.

## 보존한 동작

- JavaScript를 사용할 수 없으면 기존 연속 문서가 표시됨
- 무료 HTML ZIP 책의 격리 iframe과 원본 상호작용은 변경하지 않음
- 유료 샘플의 서버 측 페이지 제한과 이미지 접근 제어는 변경하지 않음
- 관리자 출판·결제·구매 연계 경로는 변경하지 않음
- `aria-live`, `inert`, `hidden`, 포커스 및 키보드 동작 유지
