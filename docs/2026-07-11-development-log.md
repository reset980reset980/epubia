# EPUBIA 1.4.1 개발 기록

- 작업일: **2026-07-11 (KST)**
- 프로젝트: 혜경 전자책 스튜디오 (`epub.xsw.kr`)
- 브랜치: `master`
- 운영 방식: Gunicorn 2 workers · PM2 `epubia` · Caddy HTTPS 프록시

## 이번 릴리스의 목표

원고 변환 도구였던 EPUBIA를 출판 관리자와 공개 독자가 함께 쓰는 전자책 서비스로 확장했다. 관리자는 PDF·TXT·Markdown·완성형 HTML ZIP을 출판하고 판매 정책을 설정하며, 독자는 로그인 없이 공개 서재와 무료책 또는 유료 샘플을 읽는다. 유료 구매와 상담 혜택은 운명서재가 담당한다.

## 완료한 기능

### 출판과 표지

- PDF 원본은 바이트를 그대로 보존해 한글·레이아웃 손상 없이 다시 출판한다.
- TXT·Markdown은 한글 글꼴을 포함한 EPUB 3·PDF·Markdown으로 만든다.
- `index.html`을 포함한 HTML ZIP은 기존 CSS·JavaScript·이미지·글꼴과 화면 구성을 보존한다.
- 파일 선택과 드래그 앤 드롭을 지원하며 기본 업로드 한도는 100MB다. 관리자는 10~500MB 범위에서 변경할 수 있다.
- AI 표지는 책 소개를 우선 사용하고, 소개가 없을 때만 원고 앞부분 최대 2,000자를 참고한다. 생성 배경 위에 서버 한글 글꼴로 제목·저자를 합성해 출판 표지와 서재 썸네일로 함께 사용한다.

### 리더와 한글 안전성

- PDF는 PC에서 왼쪽 페이지 썸네일, 모바일에서 숨김형 페이지 탭과 스와이프 이동을 제공한다.
- HTML 웹책은 별도 `html.epub.xsw.kr` 출처, CSP sandbox, 만료 서명 URL로 관리자 세션과 분리한다.
- OCR 웹책 ZIP은 검색·페이지 목차·원본 스캔 대조 자산을 그대로 보존한다.
- 모든 템플릿은 UTF-8을 사용하고 PDF/표지에는 실제 한글 글꼴을 포함한다.

### 공개 서재와 판매 설정

- `/`은 비로그인 방문자에게도 열리며 `판매 공개` 상태의 책만 허용 필드로 렌더링한다.
- 무료책은 전체 내용을 공개하고, 유료책은 관리자가 지정한 앞부분만 서버에서 제한해 제공한다.
- 관리자는 책별로 `비공개 / 판매 공개 / 보관됨`, `무료 / 유료`, 가격, 샘플 쪽수, 상담 할인 방식·상한·횟수·유효기간을 설정한다.
- 삭제는 실제 파일을 지우지 않고 보관 상태로 전환하며 기존 구매자 권리와 출판 파일을 보존한다.
- 상단·메인·하단 문구, 브랜드명, 색상, 업로드 한도와 AI 표지 설정을 관리자 화면에서 편집한다.

### 운명서재 연계

- 공개 카탈로그 API는 제목·저자·소개·표지·샘플·판매 정책만 반환하며 서버 파일 경로와 내부 메모는 제외한다.
- 유료 샘플의 구매 버튼은 `saju.xsw.kr/books/<book_id>`로 연결한다.
- 구매자 전체 열람은 90초 HMAC 교환 티켓과 1회용 nonce, 숨김 POST 전달을 사용한다.
- 판매가 중단되거나 보관된 책도 기존 구매자는 소유권 확인 후 계속 읽을 수 있다.

## 보안과 장애 방지

- 레거시 책은 판매 정보가 없어도 자동 공개하지 않고 안전한 `비공개` 기본값으로 읽는다.
- 공개 응답은 manifest 전체가 아닌 허용 목록으로 구성한다.
- 공개/관리자 화면이 같은 `/`을 사용하므로 `Cache-Control: private, no-store`와 `Vary: Cookie`로 캐시 혼합을 막는다.
- 로그아웃 뒤 브라우저 뒤로가기로 관리자 설정이 복원되지 않도록 보호 HTML도 `no-store`로 응답한다.
- 만료된 세션으로 설정 POST를 시도하면 POST 전용 주소가 아니라 로그인 후 해당 설정 섹션으로 안전하게 복귀한다.
- HTML ZIP은 경로 탈출, 심볼릭 링크, 실행 파일, 중첩 압축, 과도한 파일 수와 압축률을 거부한다.
- 공유 열람 키·세션 키·OpenAI 키·운영 DB·업로드 원고는 Git에 포함하지 않는다.
