OpenAI에는 책 소개가 있으면 소개만 보내고, 소개가 없을 때만 원고 앞부분 최대 2,000자를 보냅니다. 글자 없는 배경을 만든 뒤 한글 제목과 저자는 서버 글꼴로 합성하며, 완성된 표지를 EPUB·웹 리더·서재 썸네일에서 함께 사용합니다.

F

HTML BOOK PACKAGE

HTML 책은 ZIP 하나로

GPT나 편집 도구가 만든 웹 전자책 폴더를 통째로 압축해 올리면 됩니다. 첫 화면은 ZIP 최상위 또는 하나의 포장 폴더 안에 있는 index.html이어야 하며, 내부 연결은 상대 경로를 사용하세요.

나의-전자책.zip ├─ index.html 필수 ├─ css/ · js/ 선택 ├─ images/ · fonts/ 선택 └─ text/ · ocr_pages.json 선택

인터넷에 연결된 외부 파일보다 CSS·JavaScript·이미지를 ZIP 안에 함께 넣어야 모든 환경에서 같은 화면으로 열립니다. 안전을 위해 압축 해제 후 최대 300MB, 파일 2,000개, 개별 파일 50MB까지 허용합니다.
